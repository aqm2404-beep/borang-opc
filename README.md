# MeterCheck (versi umum) · LPC & OPC

Borang digital Kesediaan Tapak LPC (MTER-750-76-QR-03) dan Senarai Semak Pemeriksaan Jangka OPC.
Format PDF sama dengan borang rasmi (template asal).

- Tiada login, tiada Google Drive. PDF dimuat turun / dikongsi terus dari telefon.
- Setiap pengguna isi **Profil** sendiri: nama, no. pekerja, jawatan, telefon, stesen dan cop (muat naik gambar atau jana daripada teks).
- Data disimpan dalam telefon pengguna sahaja (localStorage / IndexedDB).

Statik sepenuhnya: deploy terus ke Vercel (Framework: Other, tiada build).
